# SD WebUI Infinite Canvas

一个无限画布插件，适用于[WebUI Forge - Neo](https://github.com/Haoming02/sd-webui-forge-classic/tree/neo)。

## 特性
- 自动扩展和放大画布
- 带边缘修复的局部重绘
- 基于Segment Anything的魔棒工具
- 工程读取和保存

## 安装
1. 打开WebUI
2. 选择 Extensions 导航栏，选择 Install from URL
3. 粘贴这个repo 的 URL 然后点击 Install
4. 重启WebUI

## 使用方法
内置一个教程，可随时查看。

在拉取此Repo时还会获得`tutorial.infcanvas`，可加载此工程直接点击 Generate 按钮，观察效果。

建议搭配`anima`模型使用。
